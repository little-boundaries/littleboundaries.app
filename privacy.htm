YOUR FAMILY’S INFORMATION

Privacy starts at home.

Little Boundaries is designed to create restrictions profiles on your Mac, without a developer account or developer backend.

This policy describes this website and the current development app, version 1.0.0 (2). It is not a claim that Apple’s services, GitHub, your browser, or the entire Mac operate without network traffic.

What stays on your Mac

Family supervision identities and saved device unlock tokens are stored in the local Mac Keychain with synchronization disabled. Restriction choices are used locally to create profiles. Approved settings catalog data is stored locally. The app has no analytics or automatic crash uploader and does not upload family names, device identifiers, profiles, identities, or tokens to us.

Connections you choose

Checking for a settings catalog update sends a request directly to GitHub. GitHub receives ordinary connection information, including your IP address, and an app-identifying request header. Checks are manual; the app does not include a GitHub login or send family settings or device identifiers with the request. GitHub’s privacy practices apply to that connection. The private development catalog is not publicly downloadable yet.

The app verifies catalog signatures, shows changes for review, and requires approval before saving new defaults. Approving a catalog never changes an installed device profile automatically. Catalog updates provide supported settings data, not executable code.

Apple Configurator may contact Apple for activation and software services. Opening an Apple App Store or privacy-policy link opens an external page. Apple and the browser or hosting provider handle those requests under their own practices.

Files you export

You choose where to save profiles and encrypted supervision identity backups. A destination you select may be cloud-synced or shared. Keep identity backups and their passwords secure. A profile with a removal password contains that password in readable XML; do not share it with your child or reuse an Apple Account password.

Device operations temporarily use local private-key files with restricted permissions. The app removes these after an operation, but a crash or power loss may leave temporary files. FileVault is recommended for the Mac.

Children’s information

The app is intended for use by parents and guardians. It does not provide remote monitoring or read children’s messages or browsing activity. Creating Apple Accounts, Family Sharing, and Screen Time settings happens through Apple, not through a Little Boundaries account.

This website and GitHub Pages

This site is operated by the Little Boundaries project and hosted by GitHub Pages. These pages include no analytics scripts, advertising, tracking cookies, account forms, remote fonts, or third-party image requests. We do not add a visitor tracking service.

GitHub states that it logs and stores visitors’ IP addresses for security purposes, even if they are not signed in. GitHub handles hosting-related information under its own privacy practices and retention policies. We do not set or control GitHub’s retention period.

GitHub Pages data collection · GitHub Privacy Statement

Links to Apple and GitHub take you to those services when you follow them. Your browser and those services may exchange ordinary connection information. Their own privacy policies apply.

Questions and information you choose to share

Contact the Little Boundaries project through the website repository’s issues. Issues are public: do not post children’s names, account details, device identifiers, passwords, profiles, keys, or tokens. If your question needs a private conversation, ask for a private contact route without including those details. Information you voluntarily post on GitHub is handled by GitHub and is visible to others.

Development status and policy changes

The Mac app is still in development and has no public download yet. Public signing, notarization, and physical-device validation are pending. The app source repository is private; publication is planned for parents and researchers to inspect it. The website source is public in its separate repository.

We will update this page and its effective date when practices change. Review it before using a future release, especially if a new feature introduces a network connection or a different storage practice.
