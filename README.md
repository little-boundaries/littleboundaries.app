# Little Boundaries website

Public informational website for [littleboundaries.app](https://littleboundaries.app), hosted on GitHub Pages. The Mac app is in development and is not distributed from this repository.

## Publication

GitHub Pages publishes the `main` branch from the repository root. `CNAME` binds the custom domain; `.nojekyll` serves the static files without Jekyll processing. Public HTML is indexable and the sitemap lists six canonical pages. The 404 page is intentionally noindex. No executable browser scripts, external fonts, analytics, package installation, or build step are required. JSON-LD is declarative metadata.

Edit the HTML and CSS, review changes, and push to main to publish an update. Update the sitemap when pages are added or removed. Keep privacy disclosures and Apple references current. No app keys, supervision identities, profiles, catalog signing credentials, or family data belong in this repository.

## Privacy and support

The site contains no visitor analytics or forms. GitHub Pages logs visitors’ IP addresses for security; see privacy.htm and GitHub’s privacy statement. For project questions or website issues, use this repository’s issues. Issues are public: never post private family or device details. App code publication is planned separately; its repository remains private during development.
